The ANN.m program runs in MATLAB software; there is no need to install this program. There are two ways to run this program.
The program is saved in the MATLAB program directory; open this program in the MATLAB app, or copy the ANN.m program, open a new script in the MATLAB app, and paste the program.
The program can be run through the app. 
The necessary data points for the input and output variables are saved in the data folder.
